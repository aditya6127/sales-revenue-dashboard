# Sales & Revenue Analysis Dashboard

An interactive Sales & Revenue Analysis Dashboard built using Python, Streamlit, Pandas, and Plotly.

The dashboard helps analyze sales performance, revenue trends, products, categories, and regions through interactive filters and visualizations.

## Features

- Total Revenue KPI
- Total Orders KPI
- Total Units Sold KPI
- Monthly Revenue Trend
- Revenue by Region
- Revenue by Category
- Top Performing Products
- Interactive Region, Category, and Product filters
- Sales data table
- Product performance analysis
- Regional performance analysis
- Business insights based on the sales data

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- Excel

## Dataset

The dashboard uses sales transaction data containing:

- Order ID
- Order Date
- Product
- Category
- Region
- Customer
- Quantity
- Unit Price
- Revenue
- Salesperson

The dataset contains 500 sales orders covering the year 2025.
